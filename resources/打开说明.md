本包为 **0.5.16**，完整版本号以软件内显示为准。注册和登录会连接来信账号服务；登录后可免费自助领取 5 GB 网络体验，领取起 48 小时有效，每个账号一次，后续套餐另付费。一份配置最多 3 台设备同时使用，流量总额另计。本版提供六个 AI 的官方获取入口；Codex、Claude Code、Hermes 可分别接入自己的 API Key。上游 Key 加密保存在工具箱，AI 软件配置只写入本机服务地址与本机访问凭证，不会一次改动三个 AI。请从来信 AI 工具箱正式下载页 https://laixin.work/ 或发包人提供的链接下载；不要使用来源不明的同名软件。

本包没有任何人的通道私钥或 AI 账号，不可作为已经开通的服务售卖。

## 这一版包含什么

- 账号：注册、登录、一次性恢复码找回、免费体验主动领取、付费套餐购买。
- 网络：领取来信签发的通道配置、连接与断开、到期处理；可查看经过工具箱本机代理入口的累计上下行流量，并查询域名或 IP 的本机分流说明；Windows 通道已接入。
- 故障回传：连接失败时回传失败原因码给后台聚合，帮助更快定位；只传固定字段，不带 IP、地址、配置内容或你电脑上的文本；可在设置里关闭。
- 故障记录：连接、恢复和常驻进程遇到异常时会留下结构化记录，客服能区分具体是哪一步失败，不再只看到一条笼统错误。
- 网络稳定性：空闲时不再频繁写入流量状态；Windows 清理卡住的后台任务时会连同残留子进程一起处理，减少重开后仍留在后台的情况。
- 账号与服务：同时添加多个 AI 账号时不会互相覆盖登记；服务端短暂限流时会进行有限的安全重试，成功后再继续读取。
- 错误提示：程序内部错误、网络路径问题和本地写入失败分开说明，不再把内部错误一律提示成清理磁盘。
- Intel Mac 更新：已安装版本不低于更新清单版本、但清单缺少 Intel 资源时，会正确显示“当前已是最新可用版本”，不再误报“暂时无法检查更新”。
- 安装 AI：Codex、Claude Code、Hermes、DeepSeek Harness、智谱 ZCode、Kimi Code 都有官方入口。在对应 AI 的「下载/版本信息」点「检测版本」查看本机情况；「官方下载」打开官方来源，「查看 GitHub」用于查看源码与发行说明（智谱 ZCode 不提供该入口）。工具箱不改动这些软件的安装包。
- 账号总览：左卡下拉查看四家 API 的 Key 状态、余额与服务面板，默认 DeepSeek；回到总览时跟随「模型 API」中真正启用的渠道，下拉查看本身不切换路由。Codex、Claude Code 的右卡为官方套餐；Hermes 没有官方模型套餐。读不到的余额或额度会明确提示，不等于已经用完。
- 模型 API：在 Codex、Claude Code 或 Hermes 各自页面添加或编辑 Key、选择默认模型、测速、保存并验证、启用。四个入口为 DeepSeek API、智谱GLM官方套餐、Kimi 开放平台 API、Kimi Code官方套餐；Kimi 的开放平台 Key 与会员 Key 是两个不同来源，不能混填。操作仅影响当前 AI；使用 API 时保持工具箱运行，完全退出并重开对应 AI 后发一条消息确认。Codex、Claude Code 也可在官方行发起登录，由官方页面授权；Hermes 只使用所接入的模型 API。
- 模型 API 状态：选中并写好配置后如实显示「已配置」；是否真的在用，以「已观察到软件调用」的证据为准。
- Hermes 解除接管：Hermes 页新增「解除工具箱接管」；有可信备份时恢复接入前配置，没有备份会如实说明，不猜原值。
- 使用回执（Mac）：在「模型 API」页主动生成脱敏使用回执，可复制或保存，由你自行发送；工具箱不会自动上传。
- 客服：企业微信客服入口。
- 设备信息：电脑基本配置只有你主动点「发送」才会上报，成功后给回执号；将发送的字段范围在客服协助区写明。
- 支付与服务摘要：「我的账号」新增支付与服务摘要，网络套餐付款、账号订阅订单与账号分享租单各看到真实状态和下一步。
- 账号订阅：Codex / Claude Code 各有三档可办理套餐；下单、人工办理进度和本人领取入口都在「账号订阅」。可用付款方式以订单页显示为准。
- 账号分享：可浏览账号租用、API 额度包、API 周期包三种标准模板；需求者和供给者自行填写价格，供给者另填数量和交付时限。发布、下单和管理自己的记录时需要登录，页面不收集账号密码或 API Key。
- 购买与售后：工具箱本体免费使用；付费网络套餐支持的渠道以账号页面显示为准，付款核实后自动更新权益。

## 桌面使用

- 关闭窗口后，工具箱继续在后台运行，AI网络保持连接。从系统菜单栏或托盘重新打开；选择“退出工具箱”才会断开网络。
- Mac 连接 AI网络时会临时接入 HTTP、HTTPS、SOCKS 三类系统代理；断开或退出后按各自原值恢复，其他软件后来改过的设置会保留。
- 国内域名库随工具箱版本更新。已命中国内规则的请求直连，未命中规则的域名请求默认走通道；这不是对所有国内网站的覆盖承诺。
- 使用 Codex 或 Claude Code 时，AI网络连接成功后会自动接入，不需要复制命令或改设置。如果它已经打开，关掉再重新打开后继续使用即可。
- Windows 上你自己开的 cmd 或系统自带的 Windows PowerShell 里跑这些命令行 AI，也会走工具箱的网络（本版起生效）。断开时工具箱只清除自己写入的那几项，你手动改过的会保留。
- “AI 打不开？检查原因”会显示固定检查的耗时、超时或服务拒绝；它不替代目标软件的登录、额度或对话确认。
- 完成官方安装后，Codex、Claude Code、Hermes 可前往各自的“模型 API”接入。
- 工具箱会自动检查新版本，有新版时自动下载，下载完成后提醒你；“更新并重启”由你点击确认，不想自动下载可在“设置 → 更新”关闭。更新重启期间 AI网络会暂时断开，账号和配置会保留。
- AI 额度与网络流量分别在剩余 10% 及以下时提醒，同一周期不重复提醒；可在设置中关闭。
- 在设置中调整界面缩放，工具箱会记住缩放和窗口大小、位置。

## 您会拿到什么

- Mac 版是一个文件名以“来信AI工具箱”开头、以 `.dmg` 结尾的文件，分 Apple 芯片（M 系列）版和 Intel 版两个包，请按自己这台 Mac 的芯片选。不确定的话，点屏幕左上角苹果标志 →“关于本机”，看“芯片”或“处理器”那一行。
- Windows 版是一个以 `.exe` 结尾的安装文件，只适用于 64 位 Windows。
- Mac 版打开后，您会同时看到软件、`Applications`（应用程序）文件夹和这份说明。

## 在 Mac 上打开

1. 双击 `.dmg` 文件。出现的窗口里，把“来信AI工具箱”图标拖到 `Applications`（应用程序）文件夹。
2. 等复制完成后，从“应用程序”文件夹打开“来信AI工具箱统一版”。不要直接在刚才的磁盘窗口里长期使用它。
3. 第一次打开一定会被系统拦住。**这不是包坏了** —— 本版尚未取得 Apple 发布认证，未签名的软件都会被拦。系统会说两种话之一，办法不一样，请对照下面两条。
4. 提示“**无法确认开发者**”时：打开“系统设置”→“隐私与安全性”，往下找到关于“来信AI工具箱统一版”的那句提示，点“仍要打开”，再确认一次。macOS 15（Sequoia）及以后必须走这一步；macOS 14 及更早的系统也可以按住 Control 键点按图标、选“打开”，再在提示框里选“打开”。
5. 提示“**已损坏，无法打开**”时：这是系统给从网上下载的未签名软件加的隔离标记，文件本身没坏；这种情况下“隐私与安全性”里通常**不会**出现“仍要打开”。请先确认软件已经拖进“应用程序”文件夹，然后打开“终端”（在“启动台”里搜“终端”），把下面这行**原样**粘贴进去按回车（不需要管理员密码，因为软件是你自己拖进“应用程序”的）：

   xattr -dr com.apple.quarantine "/Applications/来信AI工具箱统一版.app"

   命令执行完没有任何提示就是成功了，再打开一次软件即可。
6. 若文件来源不明，请取消并联系客服，不要继续。

## 在 Windows 上打开

1. 双击收到的 `.exe` 安装文件，按安装向导完成安装；保持默认安装位置即可。
2. 此安装包未配置 Windows 代码签名，首次运行可能显示“未知发布者”“Windows 已保护你的电脑”或类似提示。
3. 只有在您确认文件由发包人直接提供、文件名也与发包信息一致时，才可选择“更多信息”→“仍要运行”。来源不明时请取消并联系发包人。

## 使用网络

登录自己的账号后，在「AI网络」页同步并应用已有权益的配置，再点击连接。一份配置最多 3 台设备同时使用，流量总额另计。没有网络权益时，可在仪表盘或「购买网络套餐」主动领取一次免费体验；后续按账号页面购买付费套餐。只有安装工具箱并不会自动获得已开通的网络。

如果发包人单独交给您一个 `.lxtpack` 文件，也可手工导入。它含您自己的通道连接凭据，请勿转发，也不要上传到公共网盘。

1. 打开“AI网络”页，选择导入配置包，选中这个文件。
2. 核对页面显示的授权、节点与有效期，再应用并连接。出现“已连”后，请实际打开要使用的 AI 并确认能收到回复。
3. 配置到期后连接会自动停止并恢复原网络设置；需要续期可到「购买网络套餐」购买，遇到问题再联系客服。

## 遇到问题怎么办

在「AI网络」展开「AI 打不开？检查原因」，选择 Codex、Claude 或 Hermes（DeepSeek），点击「开始检查」。页面分别显示基础网络、通道出口和目标服务结果；登录、额度和实际对话仍需在目标软件内确认。检查完成后点击「查看客服信息」，可复制包含本次检查结果与恢复状态的问题摘要。

打开「设置 / 客服」页可找到来信企业微信客服。请保留系统提示的完整文字或截图，并告诉客服您的 macOS / Windows 版本和您做到哪一步。不要把账号密码、验证码或其他敏感信息发给任何人。
- 余额与时段：接入 DeepSeek 或 Kimi 开放平台后，账号页显示该 Key 的余额；DeepSeek 显示当前是高峰（全价）还是空闲（半价）时段。
- 版本闸门：已知与第三方模型接口不兼容的 AI 版本（如 Claude Code 2.1.154）会在启用前提示，不会写入配置。
- 一键诊断：设置 → 帮助里点「一键诊断」，再点「复制诊断信息」发给来信客服。
- 接入配方：DeepSeek 等服务商的接口地址、模型名、已知不兼容版本由来信后台签名下发，服务商变更时工具箱不用升级。
