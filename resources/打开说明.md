# 来信AI工具箱｜第一次打开说明

本包为 **0.7.7 三平台测试版**。请只从发包人提供的安装包安装，不要使用来源不明的同名软件。注册、登录和网络配置会连接来信账号服务；安装工具箱本身不会自动获得网络或 AI 账号。

## 这次修复了什么

- 网络后台保护失败时，连接会自动选择可用的独立保护方式，避免工具箱异常退出后留下失效代理。
- 修复 Windows 卸载前置检查在部分启动环境中失败的问题，并增加失败后的“重试”。
- 修复主界面被强制结束后恢复管线长时间卡住的问题，恢复失败时守护会继续重试并保留现场阶段记录。
- 修正退出工具箱后的网络行为说明：退出会停止通道并恢复电脑原有网络设置。
- 主界面和设置页不再显示内部错误码、计划任务命令或需要电脑专业知识的处理步骤。
- 在 1.0 之前，工具箱会自动收集连接稳定性和性能趋势，用于改进网络；不收集对话内容、密钥或完整请求地址，进入 1.0 后自动停止。
- 断开、重连、退出和恢复网络设置的行为保持不变。
- 账号、网络配置和 AI 接入配置会在升级时保留。

## 第一次使用

1. 打开工具箱，注册或登录自己的来信账号。
2. 在“AI网络”页同步自己的网络权益，再点击“连接网络”。
3. 打开要使用的 AI 软件，确认可以正常使用。
4. 如果网络出现问题，先按页面提示重新连接；仍有问题时保留提示截图反馈给发包人。

## 常用操作

- 点击“断开”会恢复接管前的网络设置。
- 关闭窗口后工具箱会留在后台；从托盘或菜单栏重新打开。
- 选择“退出工具箱”会按当前连接状态完成收尾。
- “工具箱意外退出时，网络不断”是可选设置。即使这项设置没有完成，网络连接仍会自动选择可用方式；用户不需要手动运行命令。

## AI 软件

Codex、Claude Code、Hermes、DeepSeek Harness、智谱 ZCode、Kimi Code 均通过官方入口安装。工具箱不会修改这些软件的安装包。模型 API 的 Key 只在你主动配置时使用，不要把密码、恢复码或 API Key 发给任何人。

## 遇到问题

反馈时只需要提供：软件版本、Windows 或 macOS 版本、做到哪一步、完整提示文字或截图。不要提供账号密码、恢复码或 API Key。发包人会负责定位和修复。

## 平台

- Windows x64 安装包：双击 `.exe`，按安装向导完成安装。
- Mac Apple 芯片：打开 arm64 `.dmg`，把工具箱拖到“应用程序”。
- Mac Intel：打开 x64 `.dmg`，把工具箱拖到“应用程序”。

本测试版未发布到线上，也不会自动修改公开更新入口。
