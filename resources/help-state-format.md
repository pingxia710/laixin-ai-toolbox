# 「当刻状态」格式

这是工具箱向企业微信客服提供的固定、无客户信息的文本格式。字段顺序、字段名与 ` | ` 分隔符不得改动；解析器只接受这一格式。

```text
来信AI工具箱 | 软件:hermes | 平台:mac | 卡片:hermes.mac.install.open-installer | 阶段:installer-open | 原因:INSTALLER_NOT_OPENED | 通道:已连 | 系统:macOS 14.5 | 版本:0.2.0-compare.1
```

| 字段 | 含义 |
| --- | --- |
| 软件 / 平台 / 卡片 | 当前工具箱所处的软件、平台及卡片标识 |
| 阶段 / 原因 | 当前阶段代码及逗号分隔的原因代码 |
| 通道 | `已连`、`未连` 或 `未知` |
| 系统 / 版本 | 工具箱读取的系统版本与工具箱版本 |

本格式只描述工具箱自身状态；不得放入客户身份、对话内容、截图或凭据。
