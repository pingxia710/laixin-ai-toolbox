• **网络恢复：** 断开、退出或授权到期时，先恢复系统代理设置再停止通道；一次恢复未完成会自动继续处理，并在页面和诊断中说明当前结果，避免电脑代理指向已关闭端口。
• **网络争用：** 遇到 PAC、WPAD 或其他代理软件改动时，工具箱会按当前路径取证后决定复用或接管；不会把未知路径当作可用连接，也不会盲目覆盖其他软件后续写入的设置。
• **账号权益：** 登录会话、微信扫码和权益概览遇到短暂网络或服务繁忙会有限重试；已付款套餐的开通不再长时间占住其他账号的支付操作。
• **订单处理：** 取消、到期关闭或建单失败后，会清理与该订单精确关联的待处理申请；已有订单和已生效权益不会被误删或改写。
• **购买与邀请：** 邀请奖励记录达到容量上限会明确提示，不再写入损坏账号账本；套餐、订单和流量仍分别记录。
• **微信付款：** 付款二维码的定位图形已修正，常见扫码器可识别；付款是否成立仍以支付渠道和账号页的实际状态为准，请勿重复付款。
• **Windows 更新与卸载：** 卸载或更新时使用原生恢复守卫，网络还原失败会保留可恢复路径；若旧版更新通道无法启动，请到官网下载安装包后再继续使用。
• **模型 API 与界面：** Codex API 页面会按当前网络状态给出一致提示；体验流量到期会显示真实到期状态，不再误报为数据获取故障。
